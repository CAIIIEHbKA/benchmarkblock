# Benchmark - Blocked Sites (RU)

Бенчмарк доступности сайтов, заблокированных в РФ. Замеряет реальную доступность
51 сайта и YouTube-доменов, выставляет оценку и сохраняет результаты.

## Запуск

- **main.py** — интерфейс на PyQt6, запуск из Python
- **app-react/** — актуальная версия на Electron + React, собирается в EXE-инсталлятор
- **run_hidden.vbs** — запуск без окна консоли (локальный скрипт, в репозиторий не входит)

## Что меряется

1. **Сайты** — 51 домен (заблокированные в РФ + эталонные для сравнения)
2. **YouTube** — 40 доменов (youtube.com, googlevideo.com, ytimg.com и CDN-домены)
3. **Оценка** — процент доступности и итоговая оценка по шкале
4. **Выгрузка CSV** — в папке проекта

## Оценка (шкала)

| Процент | Значение |
|---------|----------|
| 90%+    | почти всё работает |
| 70%+    | хорошая доступность |
| 40%+    | средняя доступность |
| 15%+    | слабая связь |
| <15%    | практически не работает |

## Структура

```
main.py              — точка входа Python-версии
core/                — модели, тестер сайтов, тестер YouTube
ui/                  — окно, диалог оценки, виджеты YouTube
config/sites.json    — список сайтов и доменов YouTube
app-react/           — Electron + React версия (подробности в app-react/README.md)
```

## Зависимости

- Python 3.11+
- PyQt6
- requests

Установка: `pip install -r requirements.txt`
