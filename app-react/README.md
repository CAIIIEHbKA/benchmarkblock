# BenchmarkBlock (Electron + React)

Новая версия бенчмарка доступности заблокированных в РФ сайтов. Прежняя
Python/PyQt-версия осталась в корне папки — она не тронута.

Отличия от Python-версии:

- интерфейс на React, приложение работает внутри Chromium (Electron);
- собирается в **один EXE-инсталлятор** (NSIS), который ставится двойным кликом
  и создаёт ярлык на рабочем столе;
- движок замеров — на нативном Node (`node:https`, `node:dns`), без Python
  и PyQt на машине пользователя;
- список сайтов вынесен в `config/sites.json` и правится без пересборки;
- формат CSV полностью совмест со старым (разделитель `;`, BOM UTF-8, CRLF).

## Как собрать инсталлятор

Нужен только Node.js 18+ (проверить: `node -v`).

Двойным кликом: **`СБОРКА_ИНСТАЛЛЯТОРА.cmd`**

или вручную:

```bat
cd app-react
npm install
node scripts\selftest.mjs
npm run dist
```

Готовый установщик: `dist\BenchmarkBlock Setup <версия>.exe`.
При первом запуске `npm install` скачивает Electron (~115 МБ) и инструменты
electron-builder. В `.npmrc` уже прописаны зеркала npmmirror — если GitHub
доступен и вы хотите качать с него, закомментируйте строки в `.npmrc`.


## Запуск в режиме разработки

```bat
npm run dev
```

## Что делает бенчмарк

1. Проверяет 51 сайт из `config/sites.json` (10 параллельных запросов, таймаут 10 с).
2. Отдельно проверяет YouTube: 9 базовых доменов + динамически собранные
   CDN-домены `rr*---sn-*.googlevideo.com` со страницы просмотра.
3. Классификация:
   - `ДОСТУПЕН` — HTTP 2xx;
   - `ЧАСТИЧНО` — редирект или HTTP 4xx/5xx (сайт отвечает, но есть фильтры);
   - `ЗАБЛОКИРОВАН` — RST/отказ соединения, ошибка TLS (признак DPI), DNS не резолвится;
   - `ТАЙМАУТ` — нет ответа за 10 секунд.
4. Скор по попугаям: сайты — 60 % веса, YouTube — 40 %.
5. Экспорт в CSV через системный диалог сохранения.

## Структура

```
app-react/
├─ electron.vite.config.mjs   — сборка main/preload/renderer
├─ package.json               — зависимости + конфиг electron-builder (NSIS)
├─ config/sites.json          — список сайтов и доменов YouTube
├─ src/main/index.js          — окно Electron, IPC, экспорт CSV
├─ src/main/engine.mjs        — движок замеров и скоринг
├─ src/shared/csv.mjs         — генератор CSV (совместим с Python-версией)
├─ src/preload/index.js       — мост renderer ↔ main
├─ src/renderer/              — React-интерфейс
├─ scripts/selftest.mjs       — автотесты движка на локальных HTTP-серверах
├─ scripts/uicheck.mjs        — проверка, что интерфейс собранного EXE отрисовался
├─ scripts/e2e.mjs            — полный прогон бенчмарка внутри собранного EXE
└─ СБОРКА_ИНСТАЛЛЯТОРА.cmd    — сборка одним двойным кликом
```

Иконка приложения по умолчанию — стандартная Electron. Своя иконка кладётся
в `build/icon.ico` (размер 256×256), electron-builder подхватит её сам.


## Автотесты

```bat
node scripts\selftest.mjs    :: движок: локальные HTTP-серверы, интернет не нужен
node scripts\uicheck.mjs     :: проверка отрисовки интерфейса собранного EXE
node scripts\e2e.mjs         :: полный прогон бенчмарка внутри собранного EXE
```

`selftest` поднимает локальные серверы и проверяет: 200 → ДОСТУПЕН,
403 → ЧАСТИЧНО, цепочку редиректов, отказ соединения и DNS → ЗАБЛОКИРОВАН,
зависший сервер → ТАЙМАУТ, формулу скора и формат CSV.

`uicheck`/`e2e` требуют запущенного приложения с ключом
`--remote-debugging-port=9222` (порт задаётся переменной `DEBUG_PORT`).

## Важно про установку

EXE не подписан сертификатом издателя, поэтому Windows SmartScreen покажет
предупреждение «Обнаружено опасное приложение» → «Подробнее» → «Выполнить в
любом случае». Это нормально для самописной сборки; при покупке кода
подписи electron-builder подхватывает сам (переменные `CSC_LINK`, `CSC_KEY_PASSWORD`).

Установка в `%LOCALAPPDATA%\Programs\BenchmarkBlock` без прав администратора,
можно выбрать свою папку. Ярлыки: рабочий стол + меню «Пуск». Удаление через
обычный «Установка и удаление программ» или `Uninstall BenchmarkBlock.exe`.
